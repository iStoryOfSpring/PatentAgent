# 年度趋势稳健性与技术空白反证检索开发说明

## 用户任务与交付

技术情报分析员在年度趋势图上检查一段时期的增长结论，在技术功效矩阵上选择稀疏组合并寻找可能被原词遗漏的文献。两个入口都可在无密钥的本地部署运行。分析对象固定为用户选定的数据集版本。结果给出统计口径、候选记录及限制，供复核后写入专题报告。

## 接口与用户流程

新增注册工具 `audit_trend_robustness`、`search_gap_counterevidence`。复用现有工具运行、方法登记、HTTP 快捷执行、MCP 和会话持久化。工具接受标准 scope，返回常规分析结果，包含算法身份、数据指纹、参数和证据。扩展现有结果卡片，从已执行的年度趋势或技术矩阵发起后续分析。服务端核对来源执行的状态、类型、数据版本和内容摘要，继承原筛选；矩阵来源只允许使用原结果的轴词组合或候选对。切换会话版本、失效执行或不匹配的选择返回可见错误。独立快捷工具入口允许手动输入。新增接口及结果类型均为加法，历史执行仍按原格式显示。数据库沿用现有执行记录。

## 年度趋势稳健性

输入包括日期依据、起止年、申请人和分类筛选，可由原图带入。用原趋势计数器固定日期轴和观察窗，分别以公开文献、申请和真实专利族标识计数。保留组内最早有效日期的年度归属与原成员。年份筛选在选定日期轴上执行。默认评估图上实际年份间的变化，同时列出逐年数列，区分持续增长与仅首末增长。缺失 ID 和无效日期单列覆盖；缺少可用标识、端点无观察或不足两年时标为不可比。年度为零的内部空档要可见。尾年显示已知数据截止日或“未知”，并在有足够年度时给出去掉尾年的方向作对照。不得用最近一项专利日期证明全年完整。

输出包含各口径逐年计数、起止差及方向、日期和标识覆盖、尾年检查、分歧或证据不足提示。给出造成差异的真实分组及其公开号，例如一个申请有两份公开文献，或一个组按最早日期跨年归属。展示示例数量设上限并明确截断。结论仅适用于当前数据覆盖。

## 技术空白反证检索

输入为技术手段、用途或功效，另可传两侧独立的同义词、中英文表达及 IPC/CPC 前缀。提供少量可审阅的离线双语词表作为起点，返回实际采用的词和来源。原矩阵可以基于抽样，反证检索在所选完整范围执行。保留原矩阵观察值、样本规模与检索覆盖之间的区别。手工输入也可独立检索。

按顺序执行原词双轴匹配、同义词和跨语言双轴匹配、分类线索扩展。文本轮要求同一份文献的标题或摘要同时支持两轴，英文匹配避免短词误中长词。分类线索保留实际分类及文本命中，单侧命中只作待核线索。按照公开号去重，另报已知族数、缺族数和本轮新增族。每轮显示命中、新增、重叠、可复核的有限数量候选、公开号、原文字段与原文片段。片段须能在原记录中定位。无扩展词、缺字段、没有命中和达到展示上限分别说明。宽查询的候选量就是复核成本的一部分。绝不把零命中归纳为市场空白、新颖性或自由实施结论。

## 工程边界

两种计算复用 Tool.run 的资源、参数和证据合同。输入长度、扩展数、返回示例数有界。数据只在本地处理，文本以普通文本渲染。UI 同时支持中英文操作。旧会话恢复后可以查看已持久化结果，执行失败可重试。登记两个工具、更新能力分组、使用说明、方法矩阵和工具数量契约。无新增服务、模型下载或数据库迁移。

## 验收与评测

1. 用独立构造的跨年公开记录，验证公开件数增长而申请数持平；核对分歧的公开号。验证申请日期跨公开年、缺失族 ID、单年、内部空年、部分尾年、截止时间未知。
2. 用含纺织回收与近红外分选的合成留出集，由测试作者预先标记相关文献和干扰项。运行原词基线及逐轮扩展。输出召回数/已知相关数、候选总量、误命中或精确率及新增候选的复核负担。标签仅用于事后评测。另测分类单侧命中、摘要缺失、稳定去重和证据片段。
3. HTTP 验证原执行版本、筛选继承、拒绝失效来源和可恢复结果。浏览器以真实后端和临时数据目录从年度图、矩阵候选分别运行两项功能，并逐件核查输出。快捷工具和 MCP 能发现两项方法。
4. 先跑新增定向测试，再跑后端全量、前端测试和生产构建、工具与方法契约、导入样例和离线 Chromium。按仓库规则检查工具运行时的十万条基准。记录运行结果、样本性质和未验证的外部能力。发布时可回退应用代码，无须回滚用户数据。

## 本地复算与检查

运行 `uv run --frozen --extra mcp python -m pytest -q tests/test_review_tools.py` 检查计算、来源绑定和持久化兼容；运行 `uv run --frozen --extra mcp python -m scripts.evaluate_gap_review` 查看合成留出集逐轮的召回、精确率与新增阅读量。文献位于独立的 source 目录，标签只在检索完成后读取。[操作示例](../mentor-demo-guide.md)

## 请求与响应约定

两个工具均经 `POST /api/tools/{tool_name}` 调用。独立执行可传如下请求；携带当前会话的 `session_id` 时保存执行与证据。

```json
{"params":{"date_basis":"filing","year_start":2019,"year_end":2022,"example_limit":8}}
```

```json
{"params":{"technology":"near infrared","effect":"sorting","technology_terms":["光谱识别"],"effect_terms":["分拣"],"ipc_prefixes":["B07C"],"example_limit":8}}
```

由图表发起时同时发送顶层 `session_id`、`source_execution_id` 和 `source_digest`。后者取自原图的 `result_metadata.review_digest`。服务端从保存的来源取回筛选条件；前端对趋势只需提供示例上限，对矩阵提供已选词对和可选扩展。来源类型、选择、版本或摘要冲突会返回 HTTP 409。非法独立工具参数返回 HTTP 422。

| 结果类型 | 前端与 API 消费方应读取的字段 |
|---|---|
| trend_robustness | years 为有序年份；data 每行对应一种单位，annual_counts 按年份排列。endpoint_delta、direction、sustained_growth、without_tail_direction 分别解释首末变化、方向、逐年状态和去掉尾年的方向。示例在 examples 中 |
| gap_counterevidence | data 每行对应一轮。hits、new、overlap 以公开号计数，known_families 和 new_families 仅按已知族计算。candidates 含文献、命中轴、字段和原文片段。unique_hits 为跨轮去重总数 |

示例条数默认 8，可取 1–25；每侧附加词、每种分类前缀最多 12 项，每项最多 100 字符。展示截断不改变全范围计数。来源摘要用于核对分析快照内容，访问范围沿用当前本机部署的会话与数据版本约束。
